🔥 Firebase Push Notification Test Client

Trang này dùng để nhận thử Push Notification trên máy của bạn.

1. Trạng thái Backend & Firebase

Google FCM Cloud Connected Project: notification-a0c90

Backend đã xác thực OAuth2 thành công với Google Cloud API.

2. Cách gửi thử Push Notification tới thiết bị thật

Khi bạn có FCM Token của điện thoại hoặc app web, bạn có thể gửi thử ngay từ terminal bằng lệnh:

mvn test -Dtest=FirebaseTestCli -Dfcm.token="<DÁN_TOKEN_VÀO_ĐÂY>"

3. Hoặc gửi qua REST API của Notification Platform

curl -X POST http://localhost:8080/api/v1/notifications \
  -H "Content-Type: application/json" \
  -d '{
    "recipient": "<FCM_DEVICE_TOKEN>",
    "channel": "PUSH",
    "subject": "Chào bạn!",
    "content": "Push Notification qua Firebase đã hoạt động!",
    "priority": "HIGH"
  }'
